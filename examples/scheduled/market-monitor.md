# Competitor pricing watch

Check the public pricing pages of <competitor A> and <competitor B> for changes
since the last snapshot. A signal = any price change, new plan, or removed plan.

Capture the current plan names and prices in the snapshot so next week's run can
diff against them. On a signal, summarise exactly what changed (old value → new
value) in the report and propose a follow-up task (e.g. refresh our own pricing
page or a comparison post).
